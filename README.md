# Breach VR

Тактическая VR-игра «штурм» для **Meta Quest 3S** (и Quest 3), где **карта строится из планировки твоей реальной квартиры**. Поддерживает **отслеживание рук (hand tracking)** и **контроллеры (джойстики Touch)**.

Проект написан на **чистом C++17 под Android NDK поверх OpenXR 1.1** — **без Unity и без Godot**, поэтому APK собирается в GitHub Actions напрямую, без каких-либо коммерческих лицензий.

---

## Ключевые особенности игры

### 1. Карта из реальной квартиры (`XR_FB_scene`)
- Игра интегрируется с Meta Quest Room Setup (`XR_FB_scene` / spatial entities): сканирует стены, пол, двери и мебель твоей квартиры.
- **Процедурный тактический генератор**: если комната ещё не отсканирована, генерируется детализированная тактическая квартира (лестничная площадка, гостиная с укрытиями, кухня и укреплённая спальня).

### 2. Управление руками (Hand Tracking) и контроллерами
- **Hand Tracking (`XR_EXT_hand_tracking`)**:
  - Отслеживание всех 26 суставов руки с визуализацией скелета.
  - **Жест «Пинч» (сведение указательного и большого пальцев)**: стрельба из оружия, установка заряда C4, взаимодействие.
  - **Жест «Средний пинч»**: быстрая смена магазина (перезарядка).
  - **Сжатие в кулак / ладонь**: удержание оружия, бросок гранаты.
- **Quest Touch Controllers**:
  - Полный экшен-сет: курки (Trigger), боковые хваты (Grip), плавное перемещение и snap-поворот стиками, виброотдача (haptics).

### 3. Тактическая механика штурма (CQB Breaching)
- **Тактические двери**:
  - Двери можно выбивать ногой (удары с глухим стуком), простреливать замки или взрывать направленным зарядом.
  - При подрыве дверь срывает с петель ударной волной.
- **Взрывчатка C4**:
  - Устанавливается на дверное полотно, активируется мигающий красный светодиод и таймер детонации.
  - Оглушает противников в соседней комнате.
- **Светошумовая граната M84 (Flashbang)**:
  - Физика полёта и отскока от пола/стен.
  - Ослепляет врагов на 4.5 секунды (эффект тиннитуса/звона в ушах и белый экран).

### 4. Тактическое вооружение
- **MK18 CQB Carbine**: автоматический карабин с коллиматорным прицелом, тактическим фонарём, анимацией отдачи и вспышками выстрелов.
- **P10 Suppressed Pistol**: бесшумный пистолет с глушителем и лазерным целеуказателем (красный луч).
- **Светошумовые гранаты и заряды C4**.

### 5. Тактический искусственный интеллект (CQB Enemy AI)
- Противники патрулируют комнаты квартиры, реагируют на звуки шагов, выстрелов и взрывов.
- Занимают укрытия за мебелью (диваны, столы, барные стойки), ведут огонь очередями по 3 патрона.
- Хитбоксы: голова (мгновенная ликвидация), торс, конечности.
- Реакция на светошумовую гранату (дезориентация и поднятые руки).

### 6. Встроенный процедурный пространственный звук (OpenSL ES)
- Движок синтезирует реалистичные звуки в реальном времени без внешних файлов:
  - Выстрелы карабина и глушёного пистолета
  - Мощный низкочастотный взрыв C4
  - Звон в ушах (тиннитус) от светошумовой гранаты
  - Металлический лязг перезарядки и щелчки затвора
  - Удары по двери и подтверждение попаданий (hitmarker)

### 7. Тактический шлем (HUD Visor) & Passthrough
- Проекционный интерфейс в поле зрения:
  - Индикатор брони и здоровья
  - Счётчик патронов и выбранного оружия
  - Счётчик оставшихся противников
  - Статус зачистки помещений («LIVING ROOM: SECURED»)
  - Режим тактического сканирования (голографическая сетка квартиры)
  - Поддержка сквозного зрения Passthrough (`XR_FB_passthrough`)

## Архитектура движка

```
app/src/main/cpp/
├── math_types.h           # 3D векторы, матрицы, кватернионы, лучи, AABB
├── egl_context.h/.cpp     # Инициализация EGL 1.4 и контекста OpenGL ES 3.0
├── gl_shaders.h/.cpp      # Шейдеры: Lit (PBR фонарь/вспышки), Wireframe, Particles, HUD
├── mesh_builder.h/.cpp    # Процедурная генерация моделей оружия, врагов, комнат, дверей
├── audio_engine.h/.cpp    # Синтезатор звука OpenSL ES (стерео, 44.1 кГц)
├── input_system.h/.cpp    # OpenXR Action Sets + XR_EXT_hand_tracking (пинчи и 26 суставов)
├── apartment_scene.h/.cpp # Модель квартиры, XR_FB_scene, выбиваемые двери, коллизии
├── weapon_system.h/.cpp   # Баллистика, C4, светошумовые гранаты, частицы, лазер
├── enemy_ai.h/.cpp        # Логика противников: зрение, укрытия, стрельба, хитбоксы
├── gameplay_manager.h/.cpp# Фазы штурма, HUD шлема, статус комнат
├── openxr_engine.h/.cpp   # Главный OpenXR движок: swapchains, стерео-рендер, цикл кадров
├── main.cpp               # Точка входа NativeActivity (android_main)
└── CMakeLists.txt         # Сборка C++17, линковка OpenXR, EGL, GLES3, OpenSLES
```

## Сборка APK через GitHub Actions

При каждом пуше в ветку автоматически запускается сборка `.github/workflows/main.yml`:
1. Устанавливает JDK 17, Android SDK, NDK 26 и CMake;
2. Собирает проект `./gradlew assembleDebug`;
3. Готовый APK доступен для скачивания в разделе **Actions** → нужный запуск → **Artifacts** (`breach-vr-debug-apk`).

## Локальная сборка

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Управление

| Действие | Hand Tracking (Руки) | Контроллер Touch |
|----------|----------------------|------------------|
| Стрельба / Установка C4 | Пинч (большой + указательный) | Правый курок (Trigger) |
| Прицеливание | Направление кисти | Правый контроллер |
| Перезарядка | Пинч (большой + средний) | Кнопка A |
| Смена оружия | Жест переключения | Кнопка B |
| Тактический визор / Сетка | Тактический жест | Кнопка X |
| Перемещение | Физическое перемещение по комнате | Левый стик (плавный ход) |
| Поворот | Физический поворот тела | Правый стик (snap 45°) |
